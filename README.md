# 💻 Projeto: Segurança de Dados Sensíveis no Front-End

Este projeto é uma simulação prática desenvolvida com base no filme **Snowden**, com foco nos cuidados que um desenvolvedor Front-End deve ter ao lidar com dados sensíveis em sites ou sistemas.

## 📄 Descrição

O objetivo do projeto é demonstrar, por meio de uma página HTML e CSS, boas práticas de coleta e tratamento de dados sensíveis, considerando a **LGPD (Lei Geral de Proteção de Dados)**. A página inclui:

- Um **texto reflexivo** com base no filme *Snowden*;
- Um **formulário** com campos sensíveis e comentários explicativos;
- Um **checklist de segurança** com recomendações;
- Um **aviso de privacidade (modal/banner)** que alerta o usuário sobre a coleta de dados.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3

## 📋 Estrutura do Projeto

- `index.html`: página principal contendo o texto, formulário e checklist de conduta.
- `style.css`: folha de estilo responsável pela aparência e organização visual do conteúdo.

## 🔐 Boas Práticas Implementadas

- Uso de `type="password"` para senhas
- Comentários explicativos sobre cada dado sensível
- Aviso sobre a política de privacidade
- Uso sugerido de HTTPS
- Recomendação contra armazenamento em LocalStorage
- Validação e limpeza de dados sugeridas no checklist

## 🚨 Importância do Projeto

Inspirado no filme *Snowden*, este projeto reforça a importância de proteger a privacidade dos usuários. Pequenas falhas no front-end podem comprometer a segurança de dados valiosos.

## ✅ Checklist Interno de Conduta (resumo)

- Utilizar HTTPS sempre
- Informar o usuário sobre a política de privacidade
- Nunca armazenar dados sensíveis no LocalStorage
- Evitar senhas visíveis no HTML
- Usar bibliotecas confiáveis para mascarar dados como CPF
