Cuidados com Dados Sensíveis

Texto reflexivo com base no filme Snowden

O filme Snowden mostra como a exposição indevida a informações pode trazer sérias consequências á privacidade das pessoas. A partir disso, um desenvolvedor Front-End deve estar atento ao lidar com dados sensíveis em seus sistemas.
Informações como CPF, senha, localização e dados bancários exigem medidas de proteção, é fundamental garantir que essas informações não fiquem expostas no código fonte e no sejam armazenadas localmente de forma insegura. O uso de HTTPS é obrigatório para proteger os dados em trânsito, também é importante informar claramente o usuário como seus dados serão utilizados e armazenados, respeitando a LGPD (Lei Geral de Proteção de Dados).
Um front-end consciente colabora ativamente com a segurança do sistema ao seguir boaspráticas, trabalhar em conjunto com o back-end e manter os usuários informados sobre seus direitos e a política de privacidade.

Checklist de Segurança - Guia Interno de Conduta

  • ✔️ Utilizar HTTPS em todas as páginas que coletam dados
  • ✔️ Informar o usuário sobre a política de privacidade
  • ✔️ Não armazenar senhas em campos visíveis ou no LocalStorage
  • ✔️ Validar e limpar todos os dados antes de enviar ao servidor
  • ✔️ Usar campos type="password" para senhas
  • ✔️ Evitar exibir dados pessoais em mensagens de erro
  • ✔️ Usar bibliotecas seguras para mascarar dados como CPF e telefone
